# 5a · Training 2: Reinforcement Learning Basics：课程笔记

课件：[lecture-09-rl-basics.pdf](lecture-09-rl-basics.pdf)。页码对应本地 PDF。正文沿课件顺序整理，额外的计算与解释标为“补充理解”。

## 同一个猜数任务，为什么还需要 RL（第 1–7 页）

**Number Search** 的规则是：隐藏整数在 1 到 16 之间，最多猜四次。猜错时环境只告诉代理答案更大或更小，猜中得 1 分，耗尽机会得 0 分。课件固定本题答案为 11，并展示四条轨迹：

| 轨迹 | 动作和环境反馈 | 回报 |
| --- | --- | ---: |
| τ₁ | 8 → 更大，12 → 更小，10 → 更大，11 → 正确 | 1 |
| τ₂ | 4 → 更大，8 → 更大，12 → 更小，11 → 正确 | 1 |
| τ₃ | 16 → 更小，8 → 更大，9 → 更大，10 → 超时 | 0 |
| τ₄ | 1 → 更大，2 → 更大，3 → 更大，4 → 超时 | 0 |

4b 的 SFT 在每一步读取记录中的历史，并提高示范动作的条件概率。如果只用 τ₁，第一步监督目标就是猜 8。换成 τ₂，示范第一步变为猜 4，最后同样完成任务。课件用这一区别引出三个问题：

| 问题 | 在猜数中的表现 | RL 提供的训练信号 |
| --- | --- | --- |
| 目标错位 | 复现记录中的猜法与在四步内猜中是两个目标 | 以轨迹回报为目标，同样奖励达到结果的不同路径 |
| 数据错位 | 直接模仿失败轨迹会复制其中的选择 | 可以按结果加权，低回报在一些更新规则下也能提供信号 |
| Exposure bias | 训练总沿示范历史前进，运行时自己的猜测会产生不同历史 | 用当前策略实际采样，训练可覆盖它自己遇到的状态 |

**强化学习（RL）**循环地采样轨迹、计算回报并更新策略，使高回报轨迹的总概率上升。采样只能覆盖策略在给定任务和预算下实际走到的状态，恢复能力仍取决于探索和奖励。

## 从交互历史到期望回报（第 8–13 页）

任务实例用 $x$ 表示。在猜数题里，环境知道隐藏数字 11，策略只看到题面和反馈。第 $t$ 步历史为 $h_t=(o_0,a_0,o_1,\ldots,o_t)$。策略 $\pi_\theta(a_t\mid h_t)$ 根据历史选择动作，环境随后给出观测 $o_{t+1}$ 和奖励 $r_{t+1}$。已经猜过 8 并得到“更大”，再猜 12 并得到“更小”，代理可从历史推断候选为 9、10、11。

完整轨迹 $\tau$ 记录初始观测和每一步动作、奖励、新观测。这里使用不折扣的总回报 $R(\tau)=\sum_{t=1}^{T}r_t$。给定任务实例，轨迹概率可分解为：

$$
p_\theta(\tau\mid x)=p(o_0\mid x)\prod_{t=0}^{T-1}
\pi_\theta(a_t\mid h_t)\,
P(o_{t+1},r_{t+1}\mid h_t,a_t,x).
$$

$\pi_\theta$ 给出代理选择动作的概率，$P$ 给出执行后结果的分布。环境规则可以未知，实际交互即可从这个联合过程采样。训练目标是 $J(\theta)=\mathbb E_{\tau\sim p_\theta(\cdot\mid x)}[R(\tau)]$。若课件里的四条轨迹分别有 0.30、0.20、0.25、0.25 的概率，则期望奖励为 $0.30+0.20=0.50$。在这个二元奖励下，期望奖励也是任务成功概率。

## ReST：先采样、筛出成功，再做 SFT（第 14–16 页）

**Reinforced Self-Training（ReST）**分成采集（Grow）与改进（Improve）。先让当前策略尝试任务并给轨迹评分，再把高回报轨迹用于监督微调，可扩充已有训练数据。下一轮用更新后的策略继续采集。猜数例子保留 τ₁ 与 τ₂，对它们的动作计算普通 SFT 交叉熵，丢弃 τ₃ 与 τ₄。这里的奖励用于选择训练数据。

**补充理解**：如果每次都猜不到，单靠成功过滤无法得到新示范。此时改变任务难度、引入初始示范或调整探索策略，才可能让后续迭代产生可用样本。

## REINFORCE：怎样从离散动作得到梯度（第 17–24 页）

采样出来的动作是离散的，测试或游戏规则也通常无法反向传播。课件的解法是求**发生这条轨迹的概率**对参数的梯度。固定一条轨迹时，其观测到的回报视为常数。利用 $\nabla p=p\nabla\log p$：

$$
\begin{aligned}
\nabla_\theta J
&= \sum_\tau R(\tau)\nabla_\theta p_\theta(\tau\mid x) \\
&= \mathbb E_{\tau\sim p_\theta}
  [R(\tau)\nabla_\theta\log p_\theta(\tau\mid x)] \\
&= \mathbb E_{\tau\sim p_\theta}
  \left[R(\tau)\sum_{t=0}^{T-1}\nabla_\theta\log\pi_\theta(a_t\mid h_t)\right].
\end{aligned}
$$

最后一步用到环境转移和初始观测在给定轨迹后对 $\theta$ 没有直接依赖。模型参数改变的是采到哪些动作、进而访问哪些环境状态。用实际 rollout 的平均值估计该期望。

**从动作到 token**：如果动作 $a_t$ 是一串模型生成的 token，其对数概率是各 token 条件对数概率之和。4b 的掩码机制仍适用：用户提示和工具消息只提供上下文，由策略实际生成的动作 token 和停止标记才计梯度。训练器最小化负号形式的损失，一条轨迹中的生成 token 都乘该轨迹的回报。

~~~mermaid
flowchart LR
    X[采样任务实例] --> P[当前策略与环境交互]
    P --> R[验证器为轨迹计分]
    R --> W[按回报或优势加权生成 token]
    W --> U[更新策略参数]
    U --> P
~~~

当奖励只有 0 和 1，原始 REINFORCE 的这项损失在同一批轨迹上等价于对成功轨迹做 SFT。失败轨迹权重为零。ReST 还可汇集不同轮次的数据并批量更新，实际训练流程可能不同。

## 优势与 baseline：比较的是表现是否超出预期（第 25–29 页）

**状态价值 $V^\pi(h)$** 是从历史 $h$ 出发按当前策略继续的期望回报。**动作价值 $Q^\pi(h,a)$** 是先指定动作 $a$、后续再按策略运行的期望回报。两者之差是优势 $A^\pi(h,a)=Q^\pi(h,a)-V^\pi(h)$。

猜完 8 和 12 后，候选为 9、10、11，还剩两次机会。猜 10 若失败，依据方向反馈可唯一定位剩余答案。猜 11 若收到“更小”，还剩 9 和 10 两个候选，却只能再猜一次。课件用这两个动作解释优势如何反映未来机会。

由于真实价值未知，课件用 $\hat A_t=R(\tau)-b(h_t)$ 估计优势。baseline 可取常数、历史回报均值或单独训练的价值模型。一个 0 分回报减去正 baseline 后会得到负权重，给失败轨迹提供方向。

**为什么减去 baseline 不改变期望梯度**：固定历史 $h$，若 $b(h)$ 与本步采到的动作无关，则

$$
\mathbb E_{a\sim\pi_\theta(\cdot\mid h)}
[b(h)\nabla_\theta\log\pi_\theta(a\mid h)]
=b(h)\nabla_\theta\sum_a\pi_\theta(a\mid h)
=b(h)\nabla_\theta 1=0.
$$

这里把 baseline 作为权重使用。通过选择合适的 baseline，可以改变采样梯度的波动。后文的组内统计来自采样轨迹自身，使用同一组样本均值或标准差时，需另外分析估计量，不能直接套用这个证明。

## 双臂老虎机：把一次更新算出来（第 30–34 页）

动作 A 得 1，动作 B 得 0。策略使用 $p=\pi_\theta(A)=\sigma(\theta)=0.25$。因此 $\partial_\theta\log\pi_\theta(A)=1-p=0.75$，$\partial_\theta\log\pi_\theta(B)=-p=-0.25$。

| 采样动作 | 采样概率 | baseline 为 0 的梯度估计 | baseline 为 0.5 的梯度估计 |
| --- | ---: | ---: | ---: |
| A | 0.25 | $1\times0.75=0.75$ | $(1-0.5)\times0.75=0.375$ |
| B | 0.75 | $0\times(-0.25)=0$ | $(0-0.5)\times(-0.25)=0.125$ |

两列的期望都是 0.1875。这也等于直接对 $J(\theta)=p$ 求导得到的 $p(1-p)$。课件给出的单次估计标准差从约 0.325 降到 0.108。采样到 B 时，负优势乘负对数概率梯度，仍可推动参数朝提高 A 概率的方向移动。

**信用分配**是另一件事。若只有一个终局回报和同一个 baseline，同条轨迹中的早期错误、无效步骤和最终纠正可能都得到相同权重。baseline 能减少波动或提供相对信号，具体步骤是否造成成功仍难识别。

## 中间奖励与 reward-to-go（第 35 页）

若环境在多步中发奖励，当前动作只应对它之后的回报负责。第 $t$ 步用 $R_t=\sum_{k=t+1}^{T}r_k$ 加权。此前的奖励已发生，给定历史时与本次动作选择无关。用 reward-to-go 去掉这部分噪声，可在保持期望梯度的同时减少方差。猜数题只在猜中时给分，其余奖励为 0，因此每步的 reward-to-go 都等于轨迹总回报。

## GRPO：在同一任务内比较多个尝试（第 36–38 页）

每个任务实例独立采样 $G$ 条轨迹。对同组回报求均值 $\bar R$ 和标准差 $\sigma_R$，用 $\hat A_j=(R_j-\bar R)/\sigma_R$ 作相对权重。课件例子使用组内总体标准差，且这里展示的是有差异的组：

| 同一任务上的四条回报 | 组均值 | 优势 |
| --- | ---: | --- |
| [1, 1, 0, 0] | 0.50 | [+1, +1, −1, −1] |
| [1, 0, 0, 0] | 0.25 | 约 [+1.73, −0.58, −0.58, −0.58] |
| [1, 1, 1, 0] | 0.75 | 约 [+0.58, +0.58, +0.58, −1.73] |

在第一组中，均值和标准差都是 0.5，所以成功轨迹权重从 $1-0.5$ 归一化为 +1，失败轨迹为 −1。第二组只有一个成功样本，它在组内更突出。若一个 batch 包含隐藏数字不同的任务，每题各算各的均值及标准差。

课件先展示当前策略采样时的简化策略梯度，组优势乘在生成动作的对数概率梯度上。完整 GRPO 目标还有概率比、裁剪和参考模型 KL 等项。GRPO 可通过同题多次采样估计相对表现，PPO 的常见 Agent 训练配置则另外拟合价值模型来帮助估计优势。

## DrGRPO：两处归一化改变了训练权重（第 39–42 页）

| 位置 | 课件中的 GRPO | DrGRPO 的改动与含义 |
| --- | --- | --- |
| 组优势 | 中心化后除以组标准差 | 只用 $R_j-\bar R$。移除小标准差带来的额外缩放，避免成功率接近 0 或 1 的组中出现的稀有结果被标准差额外放大 |
| token 聚合 | 每条回复除以自己的长度 | 改除共同常数 $C$。同样优势下，长错误回复的单个 token 与短错误回复的单个 token 使用相同的长度缩放 |

对 [1, 1, 0, 0]，简化 DrGRPO 使用 [+0.5, +0.5, −0.5, −0.5]。组内平均之前，成功轨迹的每个生成 token 系数是 +0.5/$C$，失败轨迹是 −0.5/$C$，工具返回仍被屏蔽。$C$ 在论文示例里可取生成预算。课件的系数示意略去了论文里的概率比和裁剪。

**零优势组**：若所有回报都为 0 或都为 1，中心化后每条都是 0，组内没有给策略梯度提供偏好。GRPO 按零优势组处理，避免直接除以零。若长期出现全失败，可检查任务难度、探索程度、冷启动轨迹和奖励是否足够细。全成功组也缺少组内相对差异。

## 复习：先看样本来源，再看动作权重（第 43–46 页）

| 方法 | 用什么数据 | 动作权重在课件简化式中的含义 |
| --- | --- | --- |
| SFT | 已记录的示范历史 | 被掩码选中的示范动作参与交叉熵 |
| ReST | 按回报筛选的采样轨迹 | 保留的轨迹做 SFT |
| REINFORCE | 当前策略执行得到的轨迹 | 乘总回报，或减去 baseline 后用优势加权 |
| GRPO / DrGRPO | 同题多次 rollout | 按同题相对表现加权，两者采用不同归一化 |

复习时可以重算猜数轨迹 [1, 1, 0, 0] 的权重：原始 REINFORCE 是 [1, 1, 0, 0]，课件简化 GRPO 是 [+1, +1, −1, −1]，DrGRPO 去掉标准差缩放后是 [+0.5, +0.5, −0.5, −0.5]，还需按各自的 token 聚合规则计算损失。下一课接着讨论异步 RL、旧策略轨迹和重要性权重。
