# 6a · Training 3: Advanced RL Algorithms：课程笔记

课件：[lecture-11-rl-advanced.pdf](lecture-11-rl-advanced.pdf)。页码采用本地 PDF 页序。课堂示意、论文报告和补充推导在文中标明。

## 用仓库测试训练一个修复 Agent（第 1–8 页）

本课接续 5a 的“采样 → 评分 → 更新”，讨论多步任务怎样获得更细的反馈、怎样利用异步采样、怎样约束更新，以及怎样发现奖励与任务要求不一致。

示例沿用 3b 的代码缺陷：默认值规则把显式的 0 当作假值，导致返回 3。验收要求缺失与 None 仍返回 3，0 返回 0，2 返回 2。一次成功轨迹可以先检查实现，提交第一次修改，发现仍有用例失败，修正后再跑测试。全部通过时轨迹得 1 分，否则得 0 分。

设任务 $x$ 包含提示与起始状态，$h_t$ 是第 $t$ 步做决定前的历史，$a_t$ 是动作。朴素 REINFORCE 用 $-R(\tau)\sum_t\log\pi_\theta(a_t\mid h_t)$ 作为最小化损失。奖励为 0 时，该轨迹不贡献这项梯度。若同题四条轨迹的奖励是 [1, 0, 0, 0]，先减组均值 0.25，中心化后的权重是 [+0.75, −0.25, −0.25, −0.25]。这是第 8 页的中心化示例，尚未除以组内标准差。

## 从轨迹分数到单步信用（第 9–17 页）

一条成功轨迹可以包含错误操作，失败轨迹也可能正确定位了缺陷。整轨迹权重对区分两类尝试有用，但会给同条轨迹内的动作同样的信号。以下方法回答不同问题：

| 信号 | 含义 | 如何得到 |
| --- | --- | --- |
| $R_t$，reward-to-go | 这次实际尝试从当前步以后拿了多少奖励 | 加总后续奖励 |
| $V^\mu(h_t)$，状态价值 | 从这个历史按采样策略 $\mu$ 继续，平均能拿多少奖励 | 对可能延续求平均，训练时通常用 critic 估计 |
| $\delta_t$，TD error | 这一步的即时奖励与下一状态价值之和，比动作前的预测高多少 | 用奖励和相邻两个价值预测计算 |
| $\hat A_t$，GAE | 这一步的信用估计，结合当前和以后的 TD error | 将后续误差逐渐降权，反向递推 |

课件的修复任务只在最后给奖励。成功轨迹每步的 $R_t$ 都是 1，失败轨迹每步都是 0，单纯改用 reward-to-go 无法区分这两条轨迹中每个动作。若从失败轨迹的同一个历史 $h_3$ 重新按 $\mu$ 延续十次，有三次成功，经验价值就是 0.3。它反映从当前局面出发仍有多大机会。

**训练 critic**：用 rollout 中实际的 $R_t$ 作为目标，最小化 $\mathbb E_t[(V_\phi(h_t)-R_t)^2]$。十条延续里三条得 1、七条得 0，预测 0.6 的均方误差为 0.30，预测样本均值 0.3 时降为 0.21。课件对比了独立价值网络和读取策略隐藏状态的价值头。独立网络的价值损失更新整个价值网络，课件所示共享主干方案在价值头输入处用 stop-gradient，价值损失只训练头部。

**TD 和 GAE 的课堂计算**：课件设置无折扣，即 $\gamma=1$。失败轨迹最后三步的价值依次从 0.3 → 0.6 → 0.4 → 0，实际每步奖励都为 0。终止历史的未来价值为 0，因此三步 $\delta_t=r_{t+1}+V_\phi(h_{t+1})-V_\phi(h_t)$ 分别为 +0.3、−0.2、−0.4。

$$
\hat A_3 = 0.3 + 0.5(-0.2) + 0.5^2(-0.4) = 0.1.
$$

也可逐步反推 $\hat A_t=\delta_t+\lambda\hat A_{t+1}$，末尾的后续优势为 0。**补充理解**：此例早期动作虽然出现在失败轨迹中，按 critic 的局部预测却改善了局面。较小的 $\lambda$ 让估计更依赖局部价值预测，较大的 $\lambda$ 纳入更多后来观测。critic 的误差会影响信用分配。

**过程奖励模型（PRM）**提供另一种密集信号。课件中的数学示例用人工标注某一步代数求解是否正确，训练模型识别步骤质量。步骤正确性可作价值的替代线索，二者的定义不同：一个衡量局部步骤，另一个预测策略继续执行的未来回报。

## 从同步等待到异步采样（第 18–22 页）

| 方案 | 调度过程 | 对训练数据的影响 |
| --- | --- | --- |
| 同步 RL | 同一批全部完成才更新，然后开始下一批 | 短轨迹完成后空等，批内由同一轮行为策略采样 |
| 异步 RL | 采样工作器继续生成，学习器并行使用已完成轨迹更新 | 减少整批等待，有的轨迹完成时学习器已经更新到较新策略 |

~~~mermaid
flowchart LR
    B[行为策略与环境交互] --> T[已完成轨迹和采样概率]
    T --> E[验证器评分与优势估计]
    E --> L[学习器按当前策略计算比率并更新]
    L -->|发布后续采样用的权重| B
~~~

**行为策略 $\mu$** 是实际产生动作的策略，**当前策略 $\pi_\theta$** 是学习器正在更新的策略。两者不同时，样本是旧策略访问过的历史与动作。补充理解：记录生成时的概率或能复原该概率的策略版本，才能用正确的分母计算比率。

## 重要性采样：动作概率之外，还要考虑历史（第 23–27 页）

固定历史 $h$ 和同一环境，定义 $\rho(a)=\pi_\theta(a\mid h)/\mu(a\mid h)$。从 $\mu$ 采样后用这个比率加权，可以恢复当前策略下的期望：

$$
\mathbb E_{a\sim\pi_\theta}[R(a)]
=\mathbb E_{a\sim\mu}[\rho(a)R(a)].
$$

课件例子中，正确修改的概率从 0.40 变成 0.70，权重为 1.75。另一个不完整修改从 0.40 变成 0.20，权重为 0.50。**补充理解**：等式需要行为策略覆盖当前策略可能采取且参与该期望的动作。行为策略根本不会采到的行为，不能靠给已有样本重新加权补上。

长轨迹中的环境转移相同，轨迹比率里这些因子相消，剩下动作概率比的乘积：

$$
w(\tau\mid x)=\frac{p_\theta(\tau\mid x)}{p_\mu(\tau\mid x)}
=\prod_{t=0}^{T-1}\frac{\pi_\theta(a_t\mid h_t)}{\mu(a_t\mid h_t)}.
$$

即使每步比率都是 1.05，100 步乘积也约为 132。少量高权重轨迹可能主导更新。CTPO 的课件图中，工具数学任务的累计对数比率随 token 位置变得更分散。

**历史分布偏差的例子**：新旧策略在“代码已加 None 检查”时运行测试的概率都是 0.50，这一步比率为 1。但形成该历史的修改，在旧策略下概率为 0.40，在当前策略下为 0.10。就这条前缀而言，当前策略到达它的概率只有原来的 0.25。只看当前动作比率无法反映前面的分布变化。

| 比率选取 | 纳入的动作 | 课件例子 |
| --- | --- | --- |
| 当前动作 | 只用当前 token 或动作的比率 | PPO、GRPO、DAPO、CISPO |
| 累计到当前 | 将前缀至当前动作的比率相乘 | CTPO |
| 完整轨迹 | 全部动作的比率相乘 | 完整重要性权重 |
| 长度归一化的回复比率 | 用全回复比率的几何平均作为回复级比率 | GSPO |

这些权重覆盖的范围不同，估计方差与更新行为也不同。GSPO 的长度归一化比率可写成 $\exp(\sum_t\log\rho_t/T)$。

## PPO 与 CISPO：同一个裁剪值，用在不同地方（第 28–35 页）

令 $\rho_t$ 为当前 token 的概率比，$c_t=\mathrm{clip}(\rho_t,\ell,u)$。这里的 $u_t$ 表示第 $t$ 个生成 token，$u_{<t}$ 表示此前上下文。课件示意区间为 [0.8, 1.2]。两种目标均写成最大化：

$$
J_{\mathrm{PPO}}=\mathbb E_t[\min(\rho_t\hat A_t,c_t\hat A_t)].
$$

$$
J_{\mathrm{CISPO}}=\mathbb E_t[\mathrm{sg}(c_t)\hat A_t\log\pi_\theta(u_t\mid u_{<t})].
$$

| 情形 | PPO 的效果 |
| --- | --- |
| $\hat A_t>0$ 且 $\rho_t>1.2$ | 该项取裁剪值，继续提高该动作概率没有额外目标收益 |
| $\hat A_t<0$ 且 $\rho_t<0.8$ | 该项取裁剪值，继续降低该动作概率没有额外目标收益 |
| 正优势但比率过低，或负优势但比率过高 | 目标仍可推动该比率往有利方向修正 |

CISPO 对裁剪后的比率使用 stop-gradient。它作为固定权重乘在对数概率梯度上，所以超出裁剪区间时，只要优势和权重非零，该项仍可产生梯度。补充理解：PPO 的区间为单样本代理目标定义平台，整体更新后的策略比率还会受到同批其他 token 和共享参数的影响。

**行为策略与参考模型的角色**。行为策略提供采样数据和比率分母。参考模型 $\pi_{\mathrm{ref}}$ 在训练中固定，用 $-\beta D_{\mathrm{KL}}(\pi_\theta\Vert\pi_{\mathrm{ref}})$ 约束偏移。另一个可选项是熵奖励 $+\alpha H(\pi_\theta)$，鼓励更广的下一 token 分布，以保留探索机会。

| 方法（第 35 页口径） | 奖励怎样变为优势 | 比率与限制 |
| --- | --- | --- |
| REINFORCE | 回报或 reward-to-go，无 critic | 新鲜采样，无比率裁剪 |
| PPO | 课件配置用 critic 与 GAE | 当前 token 比率，取未裁剪与裁剪目标的较小项 |
| GRPO | 组内比较，无单独 critic | 当前 token 比率，PPO 式裁剪 |
| CISPO | 组内比较 | 当前 token 比率，裁剪后作固定梯度权重 |
| GSPO | 组内比较 | 长度归一化的回复比率，PPO 式裁剪 |
| DAPO | 组内比较 | 当前 token 比率，PPO 式裁剪并放宽上界 |

## 奖励可靠性：区分模型失败和验证器失败（第 36–43 页）

同一个任务若采出 [0, 0, 0, 0]，组优势全为零。课件建议先定位原因：需求和失败测试是否一致，较强教师能否找到可被验证的解，四个尝试是否实际走过不同路径。全成功组也没有组内结果差异。

| 验证错误 | 重试次数例子 | 训练后果 |
| --- | --- | --- |
| 假阴性 | 实现满足四项要求，验证器却强制要求源码出现某个具体表达式 | 等价实现可能得不同奖励，模型可能学会迎合措辞 |
| 假阳性 | 只测输入 0。恒定返回 0 可得满分，默认值和正数行为却失效 | 策略可能越来越擅长利用验收缺口 |

课件列出的历史审计示例包括 SWE-bench Verified 约 81%、τ-bench Airline 约 70%、Retail 约 92% 的报告停滞或限制。这些数值对应当时的版本与审计设定。课件注明 τ-bench 后来修订了相关任务。

**奖励投机**还可能来自可访问的环境资源。课件列举通过网络或未来 Git 提交查找已发表修复、借用外部模型接口、修改测试或运行器等捷径。独立评估应覆盖未见任务、原验证器遗漏的行为、回归、重复动作和工具开销。例如恒定返回 0 的补丁在训练验证器得 1，但四个真实验收条件只通过一项。训练奖励持续提高而独立成功率没有改善时，应回看轨迹和验证器。

## 动态采样、部分奖励与探索（第 44–47 页）

**DAPO 动态采样**跳过同题结果完全相同的组，继续采样直至收集足够多的混合结果组。课堂示意保留 [0, 1, 0, 1] 和新抽到的 [0, 0, 1, 0]，跳过全败和全胜组。保留的组中失败样本也参与相对更新。补充理解：混合组稀少时，为填满一批可能需要更多 rollout。

**部分奖励**可以让全败组仍有差异。四个尝试分别通过 [0, 1, 2, 1] 项检查，终局的全通过奖励都是 0。若附加每项 0.25，部分分变为 [0, 0.25, 0.50, 0.25]，减均值后得到 [−0.25, 0, +0.25, 0]。需要确认这些中间进展确实和任务目标相关。课件举例，给表面上的网页工具调用额外分，可能诱导模型把浏览器当计算器或制造进行了搜索的表象。

**探索坍塌**：若动作分布由 [0.20, 0.60, 0.20] 变成 [0.01, 0.98, 0.01]，几乎所有轨迹都采用中间动作。熵奖励能鼓励尝试其他动作。实际诊断还可检查不同 rollout 是否在关键决策上有所变化。

## 蒸馏：给学生实际遇到的历史提供密集信号（第 48–53 页）

当学生极少完成任务，可先用成功示范热启动，再让学生练习偶尔成功的任务，逐步提高难度。课件建议把较早阶段的任务留在混合中，并用固定评估集衡量变化。

| 蒸馏方式 | 谁生成历史 | 教师看到什么 |
| --- | --- | --- |
| 固定轨迹蒸馏 | 已保存的教师或其他固定历史 | 在该历史给出下一动作的目标分布 |
| On-policy distillation（OPD） | 学生自己的 rollout | 在学生实际走到的历史上给目标分布，包括误操作之后的局面 |
| On-policy self-distillation（OPSD） | 学生自己的 rollout | 冻结的初始模型额外看到已验证解答，再为同一历史给出分布 |

课件用反向 KL 示意学生分布 $\pi_\theta$ 与教师分布 $q$ 的匹配。若学生给两动作各 0.5、教师给 0.8 与 0.2，则差异为 $0.5\log(0.5/0.8)+0.5\log(0.5/0.2)\approx0.223$。在多个学生访问的历史上平均这一项，最小化得到密集监督。最终奖励只在终局判断是否成功，教师分布可以在中间每个位置提供信号，其效果取决于教师是否能建议有效的后续步骤。

## 复习：训练异常时先定位哪一段（第 54–58 页）

| 现象 | 回查对象 |
| --- | --- |
| 成功轨迹里有明显错误，失败轨迹里有正确操作 | 终局回报、critic 的局部价值和步骤标注各自能提供什么信用 |
| 异步后大权重样本主导更新 | 行为版本、比率分母、历史偏移及裁剪机制 |
| 同题组几乎全败或全胜 | 验证器、任务难度、探索多样性与动态采样 |
| 训练奖励上升，真实任务无改善 | 独立检查覆盖、回归和可能被利用的捷径 |
| 学生偶尔犯错后就无法恢复 | 示范是否覆盖这类历史，教师能否在学生访问的状态上提供目标 |

附录的记号可沿一条轨迹复述：$\mu$ 生成样本，$\pi_\theta$ 负责学习，$\pi_{\mathrm{ref}}$ 是可选的固定参照。$r_{t+1}$ 是动作后的单步奖励，$R_t$ 是此后实际获得的总回报，$V^\mu(h_t)$ 是该历史的期望未来回报，$\hat A_t$ 是用于给样本加权的优势估计。下一课进入 RL Systems，继续讨论内存、并行和大规模执行。
